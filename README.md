# CRM Leads API

A lead-management CRM backend built with **FastAPI**, **PostgreSQL** and **SQLAlchemy 2.0**.
It models the core of a call-center / sales CRM: capturing leads, routing them to agents,
moving them through a sales pipeline and keeping a full activity history.

> Portfolio project by Sameer Ahmed Shahid, a clean, open-source reconstruction of the kind of
> lead-management systems I build professionally (client code itself is confidential).

## Features

- **JWT authentication** (OAuth2 password flow) with bcrypt-hashed passwords
- **Role-based authorization**: `admin`, `manager`, `agent`. Agents only ever see their own leads
- **Lead capture** with validation (email or phone required) and **duplicate detection**
  (case-insensitive email, normalised phone)
- **Auto-routing**: new leads go to the active agent with the fewest open leads
- **Pipeline with enforced transitions**: `new → contacted → qualified → converted` (or `lost`)
- **Activity log** on every lead: creation, assignment, status changes, edits and notes
- **Search, filtering and pagination** on the lead list
- **Pipeline stats** endpoint (counts by status and source, conversion rate) for dashboards
- **Alembic migrations**, **Pytest** test suite, **Docker Compose** and **GitHub Actions CI**
  (tests run against a real PostgreSQL service)

## Tech stack

| Layer | Tools |
|---|---|
| API | FastAPI, Pydantic v2 |
| Database | PostgreSQL 16, SQLAlchemy 2.0 ORM, Alembic |
| Auth | OAuth2 + JWT (python-jose), passlib/bcrypt |
| Testing | Pytest, FastAPI TestClient |
| DevOps | Docker, Docker Compose, GitHub Actions |

## Project structure

```
app/
  main.py          # FastAPI app and router registration
  config.py        # settings from environment variables
  database.py      # engine, session, Base
  models.py        # User, Lead, Activity + pipeline rules
  schemas.py       # request/response models (Pydantic)
  security.py      # password hashing and JWT helpers
  deps.py          # current-user and role guards
  services.py      # routing, duplicate detection, activity logging
  routers/         # auth, users, leads endpoints
alembic/versions/  # database migrations
tests/             # pytest suite
```

## Getting started

### With Docker

```bash
docker compose up --build
# API docs: http://localhost:8000/docs
```

### Locally

```bash
python -m venv .venv && source .venv/bin/activate
pip install -r requirements-dev.txt
cp .env.example .env          # point DATABASE_URL at your PostgreSQL
alembic upgrade head
uvicorn app.main:app --reload
```

Create the first admin (only allowed while no users exist):

```bash
curl -X POST localhost:8000/auth/bootstrap -H "Content-Type: application/json" \
  -d '{"email":"admin@example.com","full_name":"Admin","password":"password123"}'
```

## Running tests

```bash
pytest -q
```

The suite covers authentication, authorization rules, duplicate detection, round-robin routing,
pipeline transitions, search/pagination and stats.

## Main endpoints

| Method | Path | Who |
|---|---|---|
| POST | `/auth/token` | anyone (login) |
| GET | `/auth/me` | authenticated |
| POST | `/users` | admin |
| GET | `/leads` | all (agents see own leads) |
| POST | `/leads` | authenticated |
| GET | `/leads/{id}` | owner / manager / admin |
| POST | `/leads/{id}/status` | owner / manager / admin |
| POST | `/leads/{id}/assign` | manager / admin |
| POST | `/leads/{id}/notes` | owner / manager / admin |
| GET | `/leads/stats` | manager / admin |
| DELETE | `/leads/{id}` | admin |

Full interactive documentation is generated by FastAPI at `/docs`.
